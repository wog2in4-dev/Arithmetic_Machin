# Arithmetic_Machin
Arithmetic Machine A simple and interactive web application that performs basic arithmetic operations — addition, subtraction, multiplication, and division — using HTML, CSS, and JavaScript.


## Features
User‑friendly interface for entering numbers

Supports addition, subtraction, multiplication, and division

Real‑time calculation with instant results

Responsive design for desktop and mobile

Error handling for invalid inputs (e.g., division by zero)

## Tech Stack
HTML → Provides the structure (input fields, buttons, result display)

CSS → Styles the interface for clarity and responsiveness

JavaScript → Handles the logic for arithmetic operations and updates the UI dynamically

## How to Run
Clone the repository

Open index.html in your browser

Enter two numbers and select an operation

View the result instantly
